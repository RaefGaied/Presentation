Choix Architectural

Architecture Monolithique Modulaire

Un backend unifié, structuré en modules métiers indépendants — déployé via Docker Compose

✅ Architecture choisie pour FinBank
Monolithique  ·  Microservices  ·  Monolithique Modulaire
Pourquoi ce choix ?

Simplicité du déploiement

Un seul artefact app.jar orchestré via Docker Compose — pas de service discovery ni d'API Gateway à gérer.

Séparation des responsabilités

Modules distincts : security, workflow Flowable, service, domain — chacun indépendant sans overhead réseau.

Cohérence transactionnelle ACID

Toutes les opérations bancaires partagent une seule transaction PostgreSQL — impossible à garantir simplement en microservices.

Facilité de maintenance & test

Debugging centralisé, tests d'intégration simples, refactoring sans contrats d'API inter-services à maintenir.

Spring Boot 3 + Flowable BPMN + AI-Agent Python + React 19 = Monolithe Modulaire Hybride
